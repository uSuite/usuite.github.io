Privacy

The uSuite apps collect nothing. They have no network code, so nothing is sent, uploaded or counted, and there is no account. This page has no analytics and sets no cookies. What each app does write stays on your Mac, in the folders listed below.

Not sandboxed yet

The current releases do not run in the App Sandbox, so macOS does not ask before an app writes its own settings folder. The next minor version of each app moves into the sandbox. After that it asks once for each folder you open, keeps its own files in its container, and moves your current settings there on first launch.

sView

  • ~/.config/sview/ on first launch: config, keymap, last session.
  • In the folders you open, only when you ask: rename, move to the Trash, the marked names.
  • No permissions.

sNotate

  • ~/.config/snotate/ on first launch: config, keymap, styles.
  • In the case folder you open: the annotation sidecar, memo captions and notated/. Captures are never rewritten.
  • No permissions.

sPaste

  • ~/.config/spaste/ on first launch: config, keymap.
  • ~/Library/Application Support/sPaste/history/, readable only by you. Password manager items are never stored.
  • Accessibility, only for paste on Enter.
The full list

sCapture

  • ~/.config/scapture/ on first launch: config, keymap, profiles, state, capture log.
  • ~/Pictures/scapture/ by default: a folder per case, a PNG per capture you take.
  • Screen Recording to capture, Accessibility to place windows.
